# 🍔 TestyFood — Premium Food Ordering Platform

A high-performance, production-ready frontend for a food delivery service built with **React 19**, **Tailwind CSS v4**, and **TheMealDB API**.

## 🚀 Key Features
- **Dynamic Menu:** Real-time food data fetching from TheMealDB with category filtering.
- **Advanced Cart System:** Quantity controls, auto-recalculating totals, and persistent storage.
- **Complete Checkout Flow:** Multi-step simulated checkout with address management.
- **User Dashboard:** Comprehensive "My Account" area with order history and profile management.
- **API-First Design:** Optimized data fetching with loading states and error handling.

## 🛠️ Tech Stack
- **Framework:** React 19 (Functional Components & Hooks)
- **Styling:** Tailwind CSS v4 (Custom Design System)
- **API Integration:** Fetch API + AbortController for race-condition handling.
- **Routing:** React Router v7 (Nested & Shared Layouts)
- **Animations:** Custom CSS Keyframes + Swiper.js

## 🌟 Why This Project Stands Out
1. **Component Architecture:** High reusability (e.g., `AddressCard` works in selection, display, and management modes).
2. **Visual Excellence:** Premium UI/UX with a mobile-first responsive approach.
3. **Robust API Handling:** Implements clean data transformation layers and error recovery.

## 🏁 Getting Started
1. `npm install`
2. `npm run dev`
